# Connect a Live Chat

You can use your Chat Flow to connect users of your Channels (Facebook, Instagram, WhatsApp, Web Widget) to your agents in a Live Chat service.

After setting up your Chat Flow, you can connect it to a **Live Chat** service so your live agents can talk to users if they have concerns. We currently have Live Chat setups available for:

* MS Teams
* Slack
